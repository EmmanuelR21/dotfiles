# Hyprland Configs from Scratch

Best way to update these folders to match whatever changes made on local, would be to run:

```bash
# Assuming you have this repository in your root directory, otherwise change destination.
cp -r ~/.config/hypr/ ~/.config/waybar/ ~/dotfiles 
```

These folders should be a simple drag and drop into the `.config` folder.

At the moment some things may be missing necessary for the configs to work properly, such as installing the right packages/fonts etc. That will be added here in this markdown file shortly.
